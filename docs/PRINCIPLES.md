# 系统原理

## 1. 为什么要分成“检测 + 识别”

车牌识别不是单一分类问题，而是两个连续任务：

1. 图像中哪里可能有车牌
2. 车牌区域里写了什么

YOLO 擅长第一个问题，PaddleOCR 擅长第二个问题。两阶段结构将任务拆开，便于分别优化、调试和评估。

```text
P(车牌区域 | 图像) → YOLO
P(字符序列 | 车牌区域) → PaddleOCR
```

两阶段误差会传递：YOLO 漏检时，OCR 根本看不到车牌；YOLO 裁得过紧或包含太多背景时，OCR 置信度会下降。因此本项目把裁剪边界、倾斜矫正和候选融合作为核心模块，而不是附属代码。

## 2. YOLO 检测原理

### 2.1 输入与特征提取

YOLO 先将输入图像缩放并填充到固定尺寸，例如 640×640。主干网络通过卷积和残差结构提取特征，在不同深度得到不同尺度的特征图。

浅层特征保留边缘、字符纹理等细节，深层特征包含更完整的车牌语义。特征金字塔将两者融合，使模型既能发现小车牌，也能排除车标、格栅和装饰牌。

### 2.2 检测头

YOLOv8 使用 anchor-free 解耦检测头，每个位置分别预测：

- 类别概率
- 边界框中心偏移和宽高
- 检测置信度

检测损失由分类损失和边界框损失组成，其中边界框部分使用 CIoU 与 DFL。最后通过非极大值抑制去除重叠框。

### 2.3 本项目的类别设计

首选单类别：

```text
license_plate
```

颜色不由 YOLO 分类，而是裁剪后用 HSV 判断。这样可以让检测器专注学习车牌形状，避免蓝牌、黄牌、绿牌样本数量不平衡影响定位。

### 2.4 检测指标

- Precision：预测为车牌的框中，真正为车牌的比例
- Recall：真实车牌中，被检测出来的比例
- mAP@0.5：IoU 阈值为 0.5 时的平均精度
- mAP@0.5:0.95：多个 IoU 阈值下的综合平均精度

## 3. 倾斜矫正原理

普通 YOLO 输出水平矩形。倾斜车牌在水平框内会混入车体背景，导致 OCR 读取失败。

本项目的矫正流程：

```text
YOLO 框 → 扩大裁剪 → HSV 颜色掩膜 → 形态学闭运算
        → 最大轮廓 → 最小外接矩形 → 四点排序
        → 透视变换 → 水平车牌图
```

HSV 颜色掩膜分别检测蓝、黄、绿车牌背景。形态学操作连接被字符和铆钉打断的区域。

四点透视变换的目标是：

```text
p' = H · p
```

其中 H 由四个源点和四个目标点计算。变换后，倾斜车牌被拉正为水平矩形，PaddleOCR 面对的字符排列更规则。

## 4. PaddleOCR 原理

### 4.1 完整 OCR 流程

PaddleOCR 通常包含文本检测和文本识别：

- 检测模型找到文字区域
- 识别模型将文字区域转成字符序列

本项目已经由 YOLO 找到车牌区域，因此只调用识别分支。若再启用 PaddleOCR 的检测模型，会产生重复计算。

### 4.2 识别网络

车牌裁剪图先缩放到统一高度，然后由 CNN 或 SVTR 类网络提取特征。特征沿水平方向形成序列，再由 CTC 或 Attention 解码成字符。

对于车牌而言，输出应满足：

- 第一位是省份简称
- 第二位是字母
- 后续为字母和数字
- 普通车牌 7 位，新能源车牌 8 位

PaddleOCR 输出的是通用文本和置信度。它不是车牌专用解析器，因此必须增加格式约束。

### 4.3 多版本输入

项目会尝试：

1. 原始彩色裁剪
2. CLAHE 增强裁剪
3. 低照度下的 Gamma 校正裁剪

不同增强版本可以帮助同一个 OCR 模型在反光、阴影和低对比度场景下得到互补结果。

## 5. 车牌后处理原理

后处理不是简单地“去掉符号”，而是利用车牌语法进行约束解码。

### 5.1 合法性判断

普通车牌示例：

```text
京A12345
冀RDC3750
```

判定条件：

- 长度为 7 或 8
- 首字符在省份简称集合中
- 第二字符为合法字母
- 后续字符属于允许字符集
- 分隔点、空格和 OCR 标点被移除

### 5.2 位置约束纠错

字符 `I` 和 `O` 在普通车牌序号部分通常不出现，因此可以在第三位以后有条件地映射：

```text
I → 1
O → 0
```

但不能不分位置全局替换，否则第二位字母 `O` 等合法字符可能被错误修改。

### 5.3 综合置信度

本项目使用：

```text
score = 0.35 × detection_conf
      + 0.45 × ocr_conf
      + 0.20 × format_score
      + 0.05 × valid_bonus
```

这个权重不是固定真理，而是可实验参数。后续可以通过测试集搜索更合适的权重。

## 6. 视频识别原理

视频逐帧运行 YOLO + OCR 成本高，而且相邻帧结果可能抖动。

本项目采用抽帧：

- 每 N 帧运行一次完整推理
- 中间帧复用最近一次标注结果
- 汇总视频中出现频率最高的车牌

这种方式保证流程可用，并为后续实现 ByteTrack、多帧投票和稳定车牌缓存留下接口。

## 7. 评估原理

课程要求的指标包括：

### 定位准确率

```text
LA = 正确检测框数 / 测试样本总数
```

### 识别准确率

```text
RA = 完整识别正确数 / 成功定位数
```

### 整体准确率

```text
OA = 完整识别正确数 / 测试样本总数
```

### 字符准确率

```text
CA = 正确字符数 / 总字符数
```

### 字符错误率

```text
CER = Levenshtein距离 / 真实车牌长度
```

除此之外还需记录平均处理时间、YOLO 推理时间和 OCR 推理时间。

## 8. 为什么不以字符分割为主

中国车牌包含省份汉字、字母、数字、铆钉和分隔点。垂直投影法容易受到边框和铆钉干扰，切分错误会直接导致 OCR 无法读取。

因此本项目采用整牌序列识别，字符分割只作为分析或可视化扩展。技术重点放在检测、矫正、后处理和评估上。
