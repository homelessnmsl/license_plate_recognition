# 实验与评估设计

## 1. 基础指标

| 指标 | 含义 |
|---|---|
| Detection mAP@0.5 | 车牌检测综合精度 |
| Precision | 检测框中有多少是真车牌 |
| Recall | 真车牌中有多少被检测到 |
| Localization Accuracy | 每个测试图是否检测到正确车牌 |
| Recognition Accuracy | 成功定位样本中的整牌识别正确率 |
| Overall Accuracy | 全部测试样本中的整牌正确率 |
| Character Accuracy | 字符级正确比例 |
| CER | 字符错误率，越低越好 |
| Average Time | 单张图片端到端平均耗时 |
| Video FPS | 视频推理吞吐 |

## 2. 必做实验

### 实验 A：YOLO 检测

- YOLOv8n 在验证集上的 mAP、Precision、Recall
- 正常、倾斜、低照度、远距离分组统计
- 蓝牌、黄牌、绿牌分组统计

### 实验 B：倾斜矫正消融

比较：

1. YOLO 原框直接 OCR
2. YOLO 框 + 透视矫正 OCR

预期倾斜车牌在第二种方案中提升明显。

### 实验 C：后处理消融

比较：

1. PaddleOCR 原始输出
2. 去除分隔点
3. 省份/长度/字符集校验
4. 位置约束纠错 + 候选融合

记录整牌准确率和字符准确率变化。

### 实验 D：多增强输入

比较：

- 仅彩色裁剪
- 彩色 + CLAHE
- 彩色 + CLAHE + 低光 Gamma

分析提升与额外推理时间的权衡。

### 实验 E：视频抽帧

比较不同 `frame_skip`：

- 1
- 3
- 5

记录 FPS、重复识别稳定性和漏帧问题。

## 4. 结果表述原则

- 必须说明测试集规模和场景构成
- 必须区分定位率和整体识别率
- 不能只展示成功案例
- 必须保留失败案例分析
- 训练集、验证集、测试集不能混用
- 90% 是目标，不是未经验证的承诺
